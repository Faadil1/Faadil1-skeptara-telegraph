Why Telegraph is necessary

  • Skeptara declares an intelligence need; Telegraph's engine routes paid demand to live miners.
  • The clean case observed two different routed miners in the same challenge.
  • x402 makes each evidence path economically bounded and observable.
  • The product innovation is the risk-proportional objection policy + exact execution gate, not x402 by itself.

Claim boundaries

  • “Independent challenge” means reviewer/topology separation, not proven statistical independence between miners.
  • The hackathon proof uses controlled exact CVE seeds; it proves evidence enforcement, not automatic unknown-vulnerability discovery.
  • The real merge used the same exact-head/freshness/human constraints proven by the repo gate; a fully deployed GitHub adapter runtime is not claimed.
  • Human authorization was an extra real-write safety boundary. A human could not turn BLOCK or ESCALATE into PASS.

Verified final-proof activity

Minimum final-proof subset: 3 real paid challenge runs, 5 paid Telegraph evidence calls, 2 observed miners, $0.05 observed testnet spend, 1 protected denial, and 1 real exact-head merge. Setup probes and discarded experiments are intentionally excluded from this judge-facing subset.

Source of truth: repository evidence. No secret, payer address, private key, or protected GitHub credential is embedded in this page.
